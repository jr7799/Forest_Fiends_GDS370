# Fiends - Reverse Shmup Game

A 2D reverse shmup game created during our time at New England Institute of Technology. Survive up to ten minutes and collect coins and power up to unlock new characters. Play up to six characters all with their own starting ability. 

## 🎮 Play it
[Play in browser on itch.io](https://github.com/jr7799/Forest_Fiends_GDS370)

## ✨ Highlights
- Mindless fun
- Six Playable Characters

## 🛠 Built with
Unity, C#
